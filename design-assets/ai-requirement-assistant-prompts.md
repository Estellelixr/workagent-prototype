# AI 辅助生成：写作要求提示词（旧简版）

> 请优先使用 `ai-writing-requirement-assistant-spec.md`。该文件已按原型中的场景选择、已有文稿和 AI 仿写结构提取字段补全；本文件仅保留为早期简版参考。

适用位置：AI 写作「基础信息 > 写作要求 > AI 生成」和 AI 仿写「仿写要求 > AI 辅助生成」。

这不是最终文章生成提示词。该任务只根据当前已填写的少量信息，补出一段可由用户继续编辑的“写作要求”。

## 通用调用约定

传入字段：

```json
{
  "mode": "生成全文 | 生成大纲 | 大纲成文 | 继续写 | 生成结语 | AI仿写",
  "title": "用户填写的标题或主题",
  "sourceContent": "可选；大纲成文、继续写、生成结语或仿写时的已有内容",
  "referenceStyle": "可选；仅 AI 仿写，来自结构提取的风格词"
}
```

统一输出约束：只输出一段 50 至 100 字的中文写作要求；不要标题、序号、Markdown、解释、免责声明或完整正文。不得编造单位、时间、政策、数据、人物和具体事项。

## 1. 生成全文

```text
你是政务写作助手。根据用户填写的标题，生成一段可直接填入“写作要求”的简短建议。

标题：{{title}}

要求：判断标题所体现的常见文体和目的，建议正式、清晰的行文风格，并提示正文应围绕的必要内容。不要补造单位、时间、数据或具体事实；信息不足时使用通用表述。只输出 50 至 100 字的写作要求，不要输出文章、标题或解释。
```

## 2. 生成大纲

```text
你是政务写作助手。根据用户填写的标题，生成一段可直接填入“写作要求”的简短建议，重点服务于“先生成大纲”。

标题：{{title}}

要求：建议大纲应覆盖的核心层次和重点，体现结构清晰、逻辑完整、便于后续扩写。不要补造单位、时间、数据或具体事实；信息不足时使用通用表述。只输出 50 至 100 字的写作要求，不要输出大纲正文、标题或解释。
```

## 3. 大纲成文

```text
你是政务写作助手。根据标题和已有大纲，生成一段可直接填入“写作要求”的简短建议，重点服务于“大纲成文”。

标题：{{title}}
已有大纲：{{sourceContent}}

要求：提示模型严格沿用既有大纲的层级和顺序，将要点扩写为连贯、正式的正文；不要新增与大纲无关的内容。不要补造单位、时间、数据或具体事实。只输出 50 至 100 字的写作要求，不要输出文章、标题或解释。
```

## 4. 继续写

```text
你是政务写作助手。根据标题和已有正文，生成一段可直接填入“写作要求”的简短建议，重点服务于“继续写”。

标题：{{title}}
已有正文：{{sourceContent}}

要求：提示模型从已有正文自然承接，保持原有文体、语气、层级和表述习惯，避免重复上文或擅自改写既有内容。不要补造单位、时间、数据或具体事实。只输出 50 至 100 字的写作要求，不要输出续写正文、标题或解释。
```

## 5. 生成结语

```text
你是政务写作助手。根据标题和已有正文，生成一段可直接填入“写作要求”的简短建议，重点服务于“生成结语”。

标题：{{title}}
已有正文：{{sourceContent}}

要求：提示模型根据已有正文的语气和文体生成简洁、自然的收束内容，不重复全文，也不新增重大任务、事实或信息。不要擅自添加落款、日期和文号。只输出 50 至 100 字的写作要求，不要输出结语正文、标题或解释。
```

## 6. AI 仿写 - 仿写要求

```text
你是政务文稿仿写助手。根据用户的新主题、参考样稿的可用风格信息，生成一段可直接填入“仿写要求”的简短建议。

新主题：{{title}}
参考样稿风格：{{referenceStyle}}
参考样稿内容：{{sourceContent}}

要求：提示模型保留参考样稿的结构层次、行文节奏和语气特征，但围绕新主题重新组织内容；不得复制参考样稿的具体句子、数据、单位、人物或案例。只输出 50 至 100 字的仿写要求，不要输出仿写全文、标题或解释。
```

## 研发落地建议

1. 标题为空时禁用按钮，并提示“请先填写标题”。
2. `sourceContent` 和 `referenceStyle` 为空时，不拼接对应字段，避免把“空”送给模型。
3. 返回内容直接回填文本框，用户仍可编辑；回填前截断到 120 字以内。
4. 该任务建议使用低随机性参数：`temperature: 0.3`、`maxTokens: 256`，无需深度思考。
